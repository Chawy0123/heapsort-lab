# Heap Sort 互動學習網站設計規格

## 作品目的

製作一個可直接部署到 GitHub Pages 的繁體中文互動網站，讓老師能實際輸入資料、觀察最大堆積建立過程，並確認程式能連續取出最大值且完成由小到大的排序。作品同時清楚比較 Heap Sort 與 Bubble Sort 的時間複雜度，並附上具體、完整的學習心得。

## 評分目標

- 題目與方向：完整聚焦 Heap Sort、Max-Heap、sift down 與原地排序。
- 正確排序：支援連續取出最大值，最後得到正確遞增結果。
- 複雜度比較：正確說明 Heap Sort 為 O(n log n)，Bubble Sort 平均與最差為 O(n²)，最佳情況在有提前終止最佳化時為 O(n)。
- 心得：具體描述建堆、索引關係、堆積區縮小、除錯與效能比較等學習收穫。

## 使用者與主要流程

使用者是授課老師與同學。進入首頁後可以：

1. 閱讀 Heap Sort 的簡短定義與兩階段流程。
2. 使用預設資料，或輸入 2–12 個整數。
3. 按下「建立最大堆積」，看到陣列與二元樹同步更新。
4. 按「下一步」逐步完成比較、交換與向下調整，或使用「自動排序」。
5. 在每一輪看到被取出的最大值、剩餘堆積區、已排序區、比較次數及交換次數。
6. 排序結束後看到成功狀態與最終遞增陣列。
7. 閱讀演算法說明、Heap Sort／Bubble Sort 比較表與詳細心得。

## 視覺方向

採「演算法實驗室」風格：深藍黑背景、明亮青綠與琥珀色狀態色、清楚的資料卡片與等寬數字。畫面具有辨識度但保持正式，適合課堂展示。

- 堆積區：藍紫色節點。
- 目前比較：琥珀色高亮。
- 交換中的元素：粉紅／橘色高亮。
- 已排序區：綠色，並顯示鎖定狀態。
- 桌面版左右並排顯示二元樹與控制／說明；手機版改為單欄。
- 動畫以短距離位移、光暈和狀態轉場為主，不影響閱讀。

## 頁面結構

### 首屏

- 作品標題「Heap Sort Lab｜堆積排序實驗室」
- 一句核心說明
- 四個摘要：Max-Heap、O(n log n)、O(1) 額外空間、不穩定排序
- 導覽錨點：互動展示、原理、複雜度、心得

### 互動展示

- 自訂資料輸入框與驗證訊息
- 範例資料、隨機資料、重設按鈕
- 建堆、上一步、下一步、自動排序／暫停按鈕
- 二元樹 SVG 視覺化
- 陣列格子、索引、堆積區／已排序區分界線
- 當前步驟白話說明
- 統計：比較、交換、剩餘堆積大小、已取出最大值序列
- 歷程紀錄，清楚顯示每一輪取出的最大值

### 原理說明

- 完全二元樹與陣列索引：父節點 i、左子 2i+1、右子 2i+2
- 建堆從 floor(n/2)-1 開始
- 每輪將根與堆積區最後元素交換，再縮小 heapSize 並 siftDown
- JavaScript 核心程式碼展示

### 複雜度比較

| 項目 | Heap Sort | Bubble Sort |
|---|---|---|
| 最佳時間 | O(n log n) | O(n)，需提前終止最佳化 |
| 平均時間 | O(n log n) | O(n²) |
| 最差時間 | O(n log n) | O(n²) |
| 額外空間 | O(1) | O(1) |
| 穩定性 | 不穩定 | 穩定 |

並以 n = 10、100、1,000 的估算步數圖表，直觀呈現 n log n 與 n² 的成長差異；圖表只作成長趨勢說明，不宣稱為實際執行時間。

### 學習心得

以第一人稱撰寫 4–6 段，涵蓋：

- 從「每次找最大值」理解 Max-Heap 的用途。
- 建堆與正式排序是兩個不同階段。
- heapSize 分界是實作最容易出錯的地方。
- 陣列索引如何對應二元樹。
- 與 Bubble Sort 比較後對時間複雜度的理解。
- 實作動畫與測試特殊資料後的收穫。

## 技術方案

採選定的「完整作業版」：純 HTML、CSS、JavaScript，無框架與外部套件。理由是 GitHub Pages 可直接部署、老師開啟網址即可使用，也能清楚查看核心演算法程式碼。

- `index.html`：語意化頁面結構與內容。
- `styles.css`：響應式設計、節點狀態與動畫。
- `app.js`：輸入驗證、步驟生成、Heap Sort 狀態機、SVG 樹渲染與控制器。
- `README.md`：作品介紹、使用方式、部署方式與演算法摘要。

排序步驟會先由純函式產生完整快照，再由介面逐步播放，讓「上一步」、暫停與自動播放可靠運作。每一個快照保存陣列、heapSize、比較／交換位置、累計次數、訊息及取出序列。

## 正確性與邊界條件

- 僅接受 2–12 個整數，允許負數與重複值。
- 逗號、空白與中文逗號都可作為分隔符號。
- 空值、非數字、超量輸入會顯示可理解的錯誤訊息。
- 測試已排序、反向、重複值、負數、兩元素與一般亂序資料。
- 自動測試確認每個案例最終結果等於 JavaScript 數值遞增排序結果。
- 額外驗證每一輪放入已排序區的值，確實是當時堆積區最大值。

## 非目標

- 不建立登入、資料庫或多人功能。
- 不照抄教材網站的版面與文案，只使用相同且正確的演算法概念。
- 不加入與評分無關的複雜關卡或排行榜。

## 驗收條件

- 所有主要按鈕可正常操作，無無效控制。
- 預設與自訂資料皆可正確完成遞增排序。
- 每輪最大值紀錄正確，已排序區不再被更動。
- Heap Sort 與 Bubble Sort 的複雜度敘述正確。
- 桌面與手機畫面無水平溢位、文字清楚可讀。
- GitHub Pages 公開網址可載入完整網站。

## 曾考慮的方案

- 精簡展示版：開發快，但排序過程與心得較不足，難以穩定達到 95 分以上。
- 教材遊戲版：互動豐富，但題目／計分會稀釋老師最重視的排序正確性與複雜度比較。
- 完整作業版（採用）：功能、內容與開發風險最平衡，直接對準評分標準。
